#  Insurance Cost Prediction

This machine learning project analyzes a medical insurance dataset to predict individual medical costs based on various demographic and health-related factors.

---

## 📊 Dataset Overview
The dataset (`insurance (2).csv`) contains the following features:
* **age**: Age of the primary beneficiary.
* **sex**: Contractor gender (female, male).
* **bmi**: Body mass index, providing an understanding of body weights relative to height.
* **children**: Number of children/dependents covered by health insurance.
* **smoker**: Smoking status (yes, no).
* **region**: The beneficiary's residential area in the US (southeast, southwest, northwest, northeast).
* **charges**: Individual medical costs billed by health insurance.
